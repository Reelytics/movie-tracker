# Reelytics - Movie Tracking App

A modern web application for tracking your movie experiences, scanning tickets, and discovering new films.

## Features

- 🎬 Track watched movies and ratings
- 📱 Scan movie tickets with AI-powered OCR
- 🔍 Discover new movies
- 📊 View your movie statistics
- 👥 Social features and profiles

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Express.js, TypeScript
- **Database**: PostgreSQL with Drizzle ORM
- **Deployment**: Railway

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (DATABASE_URL)
4. Run development server: `npm run dev`
5. Visit `http://localhost:5000`

## Environment Variables

- `DATABASE_URL` - PostgreSQL connection string
- `NODE_ENV` - Environment (development/production)

## Deployment

This app is configured to deploy automatically to Railway when changes are pushed to the main branch.
